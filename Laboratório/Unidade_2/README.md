#  Revisão para Prova da 2ª Unidade

Eae colega, se você está aqui deve ser por que está atrás de material pra estudar pra prova de Laboratório de Estrutura de Dados II. Nesse repositório você vai encontrar o que precisa. Se puder fortalecer e deixar uma estrela no repositório como uma forma de agradecimento, ficarei muito grato!

A seguir, algumas pequenas instruções de como utilizar este repositório.

---

##  Organização da pasta

A pasta está organizada da seguinte forma:

```
Revisão_prova/
│
├── README.md
│
├── exercicios.pdf
│
└── GABARITO.md
```

###  README.md
Este arquivo contém as anotações do conteúdo, é lá onde vc vai entender a teoria e como funciona a prática.

---

###  exercicios.pdf

Arquivo contendo a lista de questões disponibilizada pelo professor.

Essas questões servem como base de estudo para a prova, sendo o principal material utilizado para revisão dos conteúdos.

---

###  GABARITO.md

Arquivo contendo a resolução e explicação das questões presentes no PDF.

Cada questão possui uma explicação detalhada com o objetivo de facilitar o entendimento dos conceitos cobrados.

---

##  Como estudar

Recomenda-se seguir a seguinte ordem:

1. Estudar pelo arquivo ```README.md```
2. Ler as questões presentes no arquivo `exercicios.pdf`;
3. Tentar resolver cada questão sozinho;
4. Conferir a resolução no arquivo `GABARITO.md`;
5. Revisar os conceitos relacionados nas anotações da disciplina.

---


Bons estudos!!!
